Task: You need to select a domain and application and build a Custom Question Answering Bot using Azure Cognitive Services Language Studio, deploy it to Azure and attach it to a channel like Facebook.

Introduction

This is a report on Azure Custom Question Answering service for building a knowledge base and developing a project focused on Credit Scoring FAQs. As mentioned, I have selected Credit Scores as a domain here for bot creation using Azure Cognitive Services Language Studio. This report aims to provide a comprehensive understanding of Azure’s cognitive language understanding capabilities and the process of creating a bot attaching with one of the channels, GroupMe to interact with the bot realtime.

Project Setup

We will now leverage the Azure Authoring client to create a new project named “CreditScore FAQs” focused on credit score related questions. It involves creating the project, adding a knowledge base, and deploying it.

Explanation:

The code performs the following steps:

  1. Creating a New Project: The script creates a new project named “CreditScoreFAQs” with English as the language. It also specifies a default answer if no relevant response is found.

  2. Adding a Knowledge Base: A knowledge base is added to the project. In this example, three articles on credit scores have been used as the source.

  3. Deploying the Project: After adding the knowledge base, the project is deployed, making it ready for use.

Show the code 
# Create new project, add knowldege base and deploy it.

authoring_client = AuthoringClient(endpoint, AzureKeyCredential(key))

with authoring_client:

    # Step 1: create project

    print("\n********************** Creating a new project *********************")
    project_name = "CreditScoreFAQs"
    project = authoring_client.create_project(
        project_name=project_name,
        options={
            "description": "FAQs for Credit Score",
            "language": "en",
            "multilingualResource": True,
            "settings": {
                "defaultAnswer": "no answer"
            }
        })

    # Output 1: View the project details

    print("view created project info:")
    print("\tname: {}".format(project["projectName"]))
    print("\tlanguage: {}".format(project["language"]))
    print("\tdescription: {}".format(project["description"]))

    # Step 2: Add a knowledge base
    print("\n********************* Adding a knowledge base *********************")

    # We are adding two knowledge bases here. A minimum of one knowledge base is required.
    # Please note, the knowledge base cannot have more than 3 sources (urls, files) in Free Tier.
    # In other words, you can add upto three sources/indices in one project, under the free tier.

    update_sources_poller = authoring_client.begin_update_sources(
        project_name=project_name,
        sources=[
            {
                "op": "add",
                "value": {
                    "displayName": "Marriage Credit FAQ",
                    "sourceUri": "https://www.experian.com/blogs/ask-experian/credit-education/life-events/marriage-and-credit/",
                    "sourceKind": "url"
                }
            },
            {
                "op": "add",
                "value": {
                    "displayName": "Credit Score Drop FAQ",
                    "sourceUri": "https://www.experian.com/blogs/ask-experian/why-did-my-credit-score-drop/",
                    "sourceKind": "url"
                }
            },
            {
                "op": "add",
                "value": {
                    "displayName": "Credit Score General FAQ",
                    "sourceUri": "https://www.experian.com/blogs/ask-experian/credit-education/faqs/credit-score-faqs/",
                    "sourceKind": "url"
                }
            },
        ]
    )
    update_sources_poller.result()

    # Output 2: list sources
    print("\nlist project sources")
    sources = authoring_client.list_sources(
        project_name=project_name
    )
    for source in sources:
        print("knowledge base name: {}".format(source["displayName"]))
        print("\tsource: {}".format(source["source"]))
        print("\tsource Uri: {}".format(source["sourceUri"]))
        print("\tsource kind: {}".format(source["sourceKind"]))


    # Step 3: deploy the project

    print("\n********************** Deploying the project **********************")

    deployment_poller = authoring_client.begin_deploy_project(
        project_name=project_name,
        deployment_name="production"
    )
    deployment_poller.result()

    # list all deployments
    deployments = authoring_client.list_deployments(
        project_name=project_name
    )

    print("view project deployments")
    for d in deployments:
        print(d)

Testing the project through SDK

Let’s test the question answering through the QuestionAnsweringClient from Python Jupyter Notebook.

1. Test by asking one question:

Show the code 
# 1. Test by asking a question
qna_client = QuestionAnsweringClient(endpoint, AzureKeyCredential(key))

with qna_client:
    question= "How Does Marriage Affect Credit?"
    output = qna_client.get_answers(
        question=question,
        top=3,
        confidence_threshold=0.2,
        include_unstructured_sources=True,
        short_answer_options=qna.ShortAnswerOptions(
            confidence_threshold=0.2,
            top=1
        ),
        project_name = "CreditScoreFAQs",
        deployment_name="production"
    )
#     print(output.answers[0])
    if output.answers:
        best_candidate = [a for a in output.answers if a.confidence and a.confidence > 0.4][0]
        print("Q: {}".format(question))
        print("A: {}".format(best_candidate.answer))
    else:
        print(f"No answers returned from question '{question}'")
Q: How Does Marriage Affect Credit?
A: Marriage has no impact on your credit. Credit reports at the three national credit bureaus (Experian, TransUnion and Equifax) do not record marital status. Credit scores, which are based on the contents of your credit reports, therefore cannot make marital status a factor in calculating your scores. 

That said, actions you take after marriage can impact your credit. If you decide to take out a mortgage or car loan together, for example, lenders will review both spouses' credit before deciding whether to approve the loan. Because of this, each spouse's credit history—before and after marriage—can impact future borrowing.

            confidence_threshold=0.5,

        ),

    if output.answers:
        best_candidate = [a for a in output.answers if a.confidence and a.confidence > 0.2][0]

        print(u"A: {}".format(best_candidate.answer))
        print('\n***********************************************************************************\n')
    else:
        print(f"No answers returned from question '{first_question}'")


    if best_candidate.qna_id:
        followup_question = "Will Changing Your Name Impact Your Credit?"

        output = qna_client.get_answers(
            question=followup_question,
            top=3,
            confidence_threshold=0.5,
            answer_context=qna.KnowledgeBaseAnswerContext(
                previous_question=first_question,
                previous_qna_id=best_candidate.qna_id

Credit scores, which are based on the contents of your credit reports, therefore cannot make marital status a factor in calculating your scores. 

That said, actions you take after marriage can impact your credit. Q: Will Changing Your Name Impact Your Credit?
A: No, name changes have [no effect on credit standing](https://www.experian.com/blogs/ask-experian/myths-vs-facts-about-marriage-and-credit/). If you change your name after marriage, you should notify the issuers of any outstanding loans or credit accounts you may have. Bot Creation

We will now create bot in Azure, test it in web chat and integrate it with the GroupMe application.

  1. Go to Deploy Knowledge Base section on the left pane, and then ‘Create a bot’ button.
  2. Fill in the required details. For Language Resource Key, go to Azure Portal, and check the resource type as “language”. Copy the Key from the endpoints section on the left pane.

Wait for Deployment to complete.

Test in Web Chat

Once the deployment is finished successfully, we can now hover to “Test in Web Chat” section of the bot page, under settings.

Create a Groupme application

Before integrating the app, we create an application on GroupMe by following the below mentioned steps:

  1. Create a GroupMe account from https://web.groupme.com/chats
  2. Navigate to the developers’ site and sign in to your account.
  3. Select Create an application for your bot.
    • Enter an application name
    • Provide callback URL as https://groupme.botframework.com/Home/Login.
    • Provide remaining details and select Agree to GroupMe’s terms and select save.
  4. Note down your app’s credentials.

Integrating Azure Bot with GroupMe

Let us now integrate our bot with the groupMe application created above. It’s a simple two step proces: 1. On the Azure bot page, go to Channels on the left pane window. 2. From the list of available channels, select GroupMe 3. Provide your Access Token and Client Id for the application created previously.

  1. Navigate to https://web.groupme.com/chats and create a new group.
  2. Now, again navigate to https://dev.groupme.com/applications/ and click on the Redirect URL in a new browser tab. Select the group name that you created in Step 4, and Save.
  3. You will now be able to chat on the groupme application.

Closing the project - resource deletion

Once the above bot integration and testing has been completed, we can start with the cleaning up of resources. We can directly clean the resource from our “Resource groups” section, which will remove all resources created under this group, like bot, language service, storage, workspace and more.
