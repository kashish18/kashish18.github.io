Introduction

This report outlines the development of a near real-time object detection tracking. Leveraging Azure Custom Vision, the notebook analyzes video frames to identify and track various types of vehicles in a provided dataset. The process begins with the collection of video dataset from Kaggle https://www.kaggle.com/datasets/robikscube/driving-video-with-object-tracking comprising different vehicle types, traffic lights, human, etc meticulously labeled with corresponding categories. Subsequently, the dataset is trained using Azure Custom Vision to develop a robust object detection model capable of accurately recognizing vehicles. Following model deployment, the notebook utilizes the deployed model to track vehicles in a 40 second video, optimizing API usage by sending one frame per second for analysis.

Converting Videos to Image Frames Using OpenCV

To initiate the object detection process, the first step involves leveraging the OpenCV library to convert the video files into individual image frames.

Video Conversion: Utilizing the cv2 VideoCapture, the video files are systematically processed to extract each frame as an image.Iterate through the frames of every video, converting each frame into a separate image for subsequent analysis.

Show the code 
import cv2
import os

# Function to save frames from a video
def save_frames_from_video(video_path):
    # Open the video file
    cap = cv2.VideoCapture(video_path)
    if not cap.isOpened():
        print(f"Error: Couldn't open video file {video_path}")
        return

    # Create output directory if it doesn't exist
    output_dir = os.path.splitext(os.path.basename(video_path))[0] + "_frames"
    os.makedirs(output_dir, exist_ok=True)

    # Get total number of frames in the video
    n_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))

    # Iterate through each frame
    for frame in range(n_frames):
        ret, img = cap.read()
        if not ret:
            print(f"Error: Failed to read frame {frame} from {video_path}")
            break
        if frame % 300 == 0:
            # Save frame as PNG image
            frame_path = os.path.join(output_dir, f"frame_{frame:06d}.png")
            cv2.imwrite(frame_path, img)

    cap.release()

# Directory containing input video files
input_directory = '../input/driving-video-with-object-tracking/bdd100k_videos_train_00/bdd100k/videos/train/'

# Iterate through only the first 10 files in the directory
file_counter = 0
for filename in os.listdir(input_directory):
    if file_counter>=60:
        break
    if filename.endswith(".mov") or filename.endswith(".mp4"):
        print(file_counter)
        video_path = os.path.join(input_directory, filename)
        save_frames_from_video(video_path)
        print(f"Frames extracted from {filename}.")
        file_counter += 1

print("All videos processed.")

This code utilizes OpenCV and OS modules to extract frames from video files:

  1. The save_frames_from_video function opens a video file, creates an output directory for frames, retrieves the total frame count, and iterates through each frame. It saves every 300th frame as a PNG image within the output directory.

  2. The script iterates through the first 60 video files in the input directory, extracts frames using the defined function, and prints a message for each video file processed.

NOTE: The above code is run in my Kaggle notebook because it is 20GB of data and Kaggle provides free persistence storage.

Uploading Images to Azure Custom Vision for Model Training

Following the extraction of image frames, the next phase involves uploading these frames to an Azure Custom Vision project for model training.

  1. Labeling Process: Each image frame, I manually labeled with relevant tags, including categories such as “car,” “Car Bonnet,” “Crash Barriers,” “Human,” “Loader Vehicles,” “Road Sign,” and “Traffic Light.” The default labeling provided by Kaggle was incorrect and insufficient.
  2. Model Training: We then upload labeled image frames to the Azure Custom Vision project, where they are utilized to train the object detection model. This training process ensures that the model can accurately identify and classify objects within the video frames.

We got a precision of 80%, which is a good indicator of identifying objects correctly. However, the recall rate of 29% suggests that the model may miss detecting some instances of the specified objects. Despite this, the mean Average Precision (mAP) is at 49.1%, indicating a moderate overall performance.

Note: 1. I set the probability threshold at 60% so that only predictions with a high confidence level are considered, thus enhancing the reliability of the detected objects.

  1. The dataset consists of a total of 71 images, with varying frequencies of labels assigned to each category as previously mentioned.
  • car is the most prevalent category with 64 occurrences, followed by
  • Car Bonnet and Loader (Heavy/SUV) Vehicles with 56 and 39 occurrences, respectively.
  • Other categories such as bike(includes motorcycle and bicycle), Crash Barriers (Roadside barricades), Human, Road Sign, and Traffic Light exhibit comparatively lower frequencies, ranging from 15 to 35 occurrences.

We can view the performance from the Azure Custom Vision UI portal

Show the code 
image_directory_for_prediction = "00207869-046fa443_frames"
output_dir = os.path.join(image_directory_for_prediction, "predictions")
os.makedirs(output_dir, exist_ok=True)

threshold = 0.4  # Adjust as needed

# Function to draw bounding boxes on image
def draw_boxes(image, predictions):
    draw = ImageDraw.Draw(image)
    for prediction in predictions:
        if prediction.probability > threshold:
            left = prediction.bounding_box.left * image.width
            top = prediction.bounding_box.top * image.height
            right = left + (prediction.bounding_box.width * image.width)
            bottom = top + (prediction.bounding_box.height * image.height)
            draw.rectangle([left, top, right, bottom], outline="red")
            draw.text((left, top), prediction.tag_name, fill="red")


# Iterate over images and perform predictions
for filename in os.listdir(image_directory_for_prediction):
    if filename.endswith(".jpg") or filename.endswith(".png"):
        image_path = os.path.join(image_directory_for_prediction, filename)
        with open(image_path, "rb") as image_contents:
            predictions = predictor.detect_image(custom_vision_project_id, published_model_name, image_contents.read())
        
        # Load image
        image = Image.open(image_path).convert("RGB")
        
        # Draw bounding boxes on image
        draw_boxes(image, predictions.predictions)
        
        # Save predicted image with bounding boxes
        predicted_image_path = os.path.join(output_dir, filename)
        image.save(predicted_image_path)

print("All predictions saved successfully.")

Converting the Image Frames back to MP4 with Bounding Box

After predicting object tags in the frames extracted from the test video, the next step involves aggregating these frames and reconstructing the video back, but this time, with the bounding boxes present.

Show the code 
# Directory containing predicted images
predicted_dir = "00207869-046fa443_frames/predictions"

# Output video file path
output_video_path = "predicted_video.mp4"  # You can change the extension to .mov if needed

# Get the list of predicted image filenames
image_files = [f for f in os.listdir(predicted_dir) if f.endswith(".jpg") or f.endswith(".png")]
image_files.sort()  # Ensure the images are sorted properly

# Get the dimensions of the first image to initialize the video writer
first_image = cv2.imread(os.path.join(predicted_dir, image_files[0]))
height, width, _ = first_image.shape

# Define the codec and create VideoWriter object
fourcc = cv2.VideoWriter_fourcc(*'mp4v')  # Change 'mp4v' to 'avc1' for .mov format
fps = 30  # Adjust as needed
out = cv2.VideoWriter(output_video_path, fourcc, fps, (width, height))

# Iterate through predicted images and add them to the video
for filename in image_files:
    image_path = os.path.join(predicted_dir, filename)
    frame = cv2.imread(image_path)
    out.write(frame)

# Release the VideoWriter and close all OpenCV windows
out.release()
cv2.destroyAllWindows()

print(f"Video saved as {output_video_path}")
Video saved as predicted_video.mp4

The above code iterates through the predicted image files, adds them to the video frame by frame using the VideoWriter module of cv2/opencv library , and finally saves the video file in the specified format (.mp4 in this case).
